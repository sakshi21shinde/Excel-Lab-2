# 📊 Excel Lab 2 – DMart Business Metrics Analysis

## 📌 Overview
This project analyzes DMart sales data using Microsoft Excel to calculate key business metrics such as **Discount Value, Net Revenue, Total Sales, and Average Order Value (AOV)**.

## 🛠️ Skills Used
- Excel Formulas
- SUM & AVERAGE Functions
- Cell Referencing
- Business Metrics Calculation

## 📈 Metrics Calculated
- Discount Value = `Sales × Discount`
- Net Revenue = `Sales − Discount Value`
- Total Sales = `SUM()`
- Average Order Value (AOV) = `AVERAGE()`
